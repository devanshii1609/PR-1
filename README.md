# PR-1
# 🐍 Python User Information & Data Types Project

> 🌟 **A beginner-friendly Python project demonstrating basic programming concepts through an interactive user information system.**

---

## 📌 Project Overview

This project is designed to demonstrate the **fundamentals of Python programming** in a simple and practical way.

The program first introduces the **advantages of Python**, then collects basic information from the user such as their **name, age, favourite number, and height**. It processes the entered information, displays the stored data with its corresponding **Python data types**, performs simple age-related calculations, and provides additional information such as an estimated birth year.

The project is especially useful for understanding how **input, variables, data types, type conversion, calculations, and formatted output** work together in Python.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- 🐍 Understand the basics of Python programming
- ⌨️ Learn how to take input from a user
- 📦 Store information using variables
- 🔤 Understand different Python data types
- 🔄 Practice type conversion
- 🧮 Perform simple mathematical calculations
- 📊 Display processed information in an organized format
- 💡 Understand why Python is popular and beginner-friendly

---

## ✨ Key Features

### 1. 🐍 Introduction to Python
The project highlights important advantages of Python, including:

- Easy-to-read and beginner-friendly syntax
- Support for multiple programming paradigms
- Extensive standard and third-party libraries
- Cross-platform compatibility
- Rapid development and prototyping
- Strong community support

### 2. 👤 User Information Collection
The program asks the user to enter:

- **Name**
- **Age**
- **Favourite Number**
- **Height in centimeters**

### 3. 📋 User Data Summary
After collecting the information, the program displays the entered values in a structured summary.

### 4. 🧩 Data Type Identification
The project demonstrates commonly used Python data types:

| Information | Python Data Type |
|---|---|
| 👤 Name | `str` |
| 🎂 Age | `int` |
| ⭐ Favourite Number | `float` |
| 📏 Height | `float` |

### 5. 🧮 Age Calculations
The program converts the user's age into:

- 📅 Age in months
- 📆 Approximate age in days

### 6. 📅 Additional Information
The project also displays:

- Recorded age
- Estimated birth year
